# Portfolio

Vite-based portfolio scaffold for Vercel deployment.

## Run locally

```bash
npm install
npm run dev
```

## Planned structure

- `src/main.js` — app entry
- `src/portfolio.js` — initialization bridge
- `src/styles/main.css` — shared styles
- future: `src/scene/*`, `src/sections/*`, `src/shaders/*`
